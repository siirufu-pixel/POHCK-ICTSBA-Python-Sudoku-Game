# POHCK-ICTSBA-Python-Sudoku-Game

This is a fully functional 9x9 Sudoku game developed using Python and Tkinter as my high school SBA (School-based Assessment) project. 

## Features
*   Interactive GUI built with Tkinter.
*   Random puzzle generation with multiple difficulty levels (Easy, Medium, God).
*   **Input Validation:** Custom `check()` algorithm to verify row, column, and 3x3 grid constraints.
*   **Hint System:** Uses a Naked Single algorithm (fun fact: I loaded my brain to make it work, and I'm still slightly surprised it runs flawlessly).
*   Timer and past player records tracking.

## How to run
Make sure you have Python installed, then run:
`python ictsba.py`
